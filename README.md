# Franchise Scorecard Dashboard

Dashboard HTML สำหรับดูผลคะแนนโรงงานแฟรนไชส์ อ่านข้อมูลจากไฟล์ Excel 11 ไฟล์
เปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งอะไร และไม่ต้องต่ออินเทอร์เน็ต

---

## วิธีใช้งาน

### เปิดดูในเครื่อง
ดับเบิลคลิกไฟล์ `index.html` ได้เลย

### อัปโหลดขึ้น GitHub
อัปโหลดทั้งโฟลเดอร์นี้ขึ้น repository แล้วเปิด GitHub Pages
(Settings → Pages → Branch: main → Save) จากนั้นเข้าที่
`https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

> ต้องอัปโหลดครบทุกไฟล์ในโฟลเดอร์ โดยเฉพาะ `data.js` และโฟลเดอร์ `vendor/`
> ถ้าขาดไฟล์ใดไฟล์หนึ่ง Dashboard จะแสดงผลไม่ครบ

---

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก + เมนู Tab ด้านข้าง |
| `styles.css` | รูปแบบและการจัดวางทั้งหมด |
| `app.js` | ตรรกะการทำงาน: ตัวกรอง กราฟ ตาราง และการสร้าง PDF |
| `auth.js` | หน้า Login เชื่อมกับ Google Sheet ผ่าน Apps Script |
| `data.js` | ฐานข้อมูลที่แปลงมาจาก Excel ทั้ง 11 ไฟล์ (288 โรงงาน) |
| `build_data.py` | สคริปต์แปลง Excel → `data.js` ใช้ตอนอัปเดตข้อมูล |
| `vendor/` | ไลบรารี Chart.js, chartjs-plugin-datalabels, html2canvas, jsPDF, ExcelJS (เก็บไว้ในเครื่อง) |
| `source-excel/` | ไฟล์ Excel ต้นทางทั้ง 11 ไฟล์ |

## การอัปเดตข้อมูล

เมื่อไฟล์ Excel มีข้อมูลใหม่ ให้ทำตามนี้

1. วางไฟล์ Excel ที่อัปเดตแล้วทับของเดิมในโฟลเดอร์ `source-excel/`
2. รันคำสั่ง

```bash
pip install openpyxl
python build_data.py
```

3. สคริปต์จะสร้าง `data.js` ขึ้นใหม่ — อัปโหลดไฟล์นี้ทับของเดิมบน GitHub

> ค่าเริ่มต้นของสคริปต์อ่านไฟล์จากโฟลเดอร์ `source-excel/` และเขียนผลลัพธ์ไว้ที่โฟลเดอร์เดียวกับสคริปต์
> ถ้าต้องการเปลี่ยนที่อยู่ ให้แก้ตัวแปร `SRC` และ `OUT` ที่บรรทัดบนสุดของ `build_data.py`

**ชื่อไฟล์และชื่อชีตต้องคงเดิม** เพราะสคริปต์อ้างอิงตามชื่อ
ถ้าเปลี่ยนชื่อชีตต้องแก้ในสคริปต์ด้วย

## หน้าจอทั้ง 4 Tab

### 1. แยกบริษัท
เลือกโรงงานทีละแห่งเพื่อดูรายงานเต็ม

- ค้นหาแบบไล่ระดับ: กิจการ → ผู้จัดการผลิต → ทีม FM → บจก./หจก. → โรงงาน (เชื่อมความสัมพันธ์กันอัตโนมัติ)
- ช่องพิมพ์ค้นหา ค้นได้ทั้งชื่อโรงงาน รหัสโรงงาน และชื่อบริษัท
- หัวรายงานแสดงคะแนนรวม ดาวสีทอง และโบนัสบาท/คิว
- กล่องคะแนน 8 หัวข้อ แสดงคะแนนไว้ด้านบนสุดของทุกกล่อง โดย Safety จัดเรียงแนวนอน 3 เรื่อง
- กราฟรายเดือน: ยอดขาย (เทียบ 2568 / 2569 / แผน), การสั่งวัตถุดิบ, CPK, NPS พร้อมตารางคะแนนรายเดือน
- กราฟแสดงตัวเลขกำกับไว้กลางแท่งแบบขนานกราฟ (แท่งเตี้ยเกินไปจะย้ายตัวเลขไปไว้เหนือแท่งให้อัตโนมัติ) · แท่ง CPK ใช้สีตามคะแนน เขียว 2.5 · เหลือง 1.25 · แดง ไม่ได้คะแนน
- รายชื่อ จบส. ที่ยังไม่อบรม และรายชื่อพนักงานที่ยังสอบไม่ผ่าน
- ปุ่ม **ดาวน์โหลด PDF** สร้างรายงาน **1 หน้า A4** หัวเรื่อง "เรียน ผู้บริหาร โรงงาน [ชื่อโรงงาน]"
  โดยใช้เลย์เอาต์ย่อเฉพาะสำหรับ PDF (กล่องคะแนน 8 หัวข้อ กราฟ 4 กราฟ ตารางคะแนนรายเดือน
  สถานะการตรวจ และรายชื่อที่ยังค้าง) ไม่ใช่การถ่ายภาพหน้าจอมาตัดแบ่งหน้า

### 2. ภาพรวม
เปรียบเทียบทุกโรงงาน กรองตามกิจการ / ผู้จัดการผลิต / ทีม FM / บริษัท
แต่ละหัวข้อแสดง 10 โรงงานต่อหน้า พร้อมปุ่มเลื่อนหน้า

| หัวข้อ | Tab ย่อย |
|---|---|
| ยอดขาย | ยอดขายรายเดือน + คะแนน |
| ยอดสั่งน้ำยา | % รายเดือน (ไฮไลท์แดงเมื่อต่ำกว่า 90%) |
| คุณภาพ | ผล CPK / คะแนน |
| การบริการ (NPS) | ผล NPS / คะแนน |
| พนักงาน | สอบผ่าน / ยังไม่ผ่าน |
| Safety – โรงงาน | ตรวจครบ / ยังไม่ตรวจ |
| Safety – รถโม่ | ตรวจครบ / ยังไม่ตรวจ |
| Safety – ผลอบรม จบส. | อบรมครบ / ยังอบรมไม่ครบ |
| สิ่งแวดล้อม | ตรวจครบ / ยังไม่ตรวจ |

### 3. รายงานรายโรงงาน
ตารางเดียวรวมทุกโรงงาน แสดงคะแนนแยกรายหัวข้อทั้ง 8 เรื่อง (ยอดขาย, วัตถุดิบ, คุณภาพ,
Safety, NPS, พนักงาน, สิ่งแวดล้อม, หักคะแนน) พร้อมคะแนนรวมและดาวที่ได้ในแถวเดียวกัน

- ตัวกรองไล่ระดับแบบเดียวกับ Tab อื่น: กิจการ → ผู้จัดการผลิต → ทีม FM → บริษัท
- ช่องค้นหาโรงงาน ค้นได้ทั้งชื่อ รหัส และชื่อบริษัท
- คอลัมน์แรกเป็น **ชื่อบริษัท** บรรทัดเดียว (ชื่อยาวเกินจะตัดด้วย "…" ชี้เมาส์ค้างดูชื่อเต็มได้)
  ตามด้วยชื่อโรงงาน — ไม่แสดงรหัสโรงงานในตารางนี้ (แต่ยังค้นหาด้วยรหัสได้ตามปกติ)
- คะแนนเต็มของแต่ละหัวข้อย้ายไปเป็นบรรทัดที่สองของหัวตาราง เช่น "ยอดขาย" บรรทัดบน
  "(15 คะแนน)" บรรทัดล่าง แทนการแสดงต่อท้ายทุกค่าในตาราง
- คอลัมน์บีบให้กะทัดรัดเท่าที่จำเป็น ตารางพอดีความกว้างหน้าจอโดยไม่ต้องเลื่อนแนวนอนบนจอทั่วไป
- **คลิกหัวตารางเพื่อเรียงลำดับ** ได้ทุกคอลัมน์ (คลิกซ้ำเพื่อสลับมาก→น้อย / น้อย→มาก)
- ค่าเริ่มต้นเรียงตามชื่อบริษัท ก–ฮ และเรียงชื่อโรงงานเป็นตัวรองในกรณีบริษัทเดียวกัน
- แสดง 20 โรงงานต่อหน้า พร้อมปุ่มเลื่อนหน้า
- **หัวตาราง (thead) lock ไว้ด้านบน** เมื่อเลื่อนดูแถวข้อมูลในตาราง — ถ้าตารางสูงกว่าพื้นที่แสดงผล จะมีแถบเลื่อนของตัวเองและหัวตารางจะค้างอยู่ด้านบนเสมอ ใช้ได้กับทุกตารางในแท็บภาพรวม รายงานรายโรงงาน และหักคะแนน
- ปุ่ม **ดาวน์โหลด Excel** ส่งออกเฉพาะข้อมูลที่กรอง/ค้นหาอยู่บนหน้าจอขณะนั้น เป็นไฟล์ .xlsx
  ตีเส้นตารางครบทุกเซลล์ หัวตารางสีเข้มตัวหนา แช่แข็งแถวหัวไว้ (freeze row) ประกอบด้วย 2 ชีต

  | ชีต | เนื้อหา |
  |---|---|
  | **รวมคะแนน** | กิจการ, บริษัท, โรงงาน, คะแนนแต่ละหัวข้อทั้ง 8 เรื่อง, คะแนนรวม, ดาว |
  | **รายละเอียด** | กิจการ, บริษัท, โรงงาน, ค่าดิบของแต่ละหัวข้อ (เช่น ยอดขายสะสม, %วัตถุดิบ,
  จำนวนพนักงาน) เคียงคู่กับคะแนนที่ได้ในหัวข้อนั้น รวม 27 คอลัมน์ |

### 4. หักคะแนน
ตารางโรงงานที่มีคะแนนติดลบ พร้อมเรื่องที่ถูกหัก
และตารางเกณฑ์การหักคะแนนอ้างอิงจากไฟล์กติกา

## เกณฑ์คะแนน (อ้างอิง rules.xlsx)

คะแนนเต็ม **100 คะแนน**

| หัวข้อ | คะแนนเต็ม | เกณฑ์ |
|---|---|---|
| ยอดขาย | 15 | >40,000 = 15 · >30,000 = 13 · >20,000 = 11 · >10,000 = 9 · <10,000 = 7 |
| การสั่งวัตถุดิบ | 5 | ≥90% ของยอดผลิต = 5 · 80–89.9% = 4 |
| คุณภาพ | 20 | CPK รายเดือนสูงสุด 2.5 · Dangerous Zone -2.5 · Manual -1.25 |
| Safety | 20 | โรงงาน 15 + รถโม่ 2 + อบรม จบส. 3 |
| การบริการ (NPS) | 18 | NPS > 75% ได้เดือนละ 2 คะแนน (เม.ย.–ธ.ค.) |
| พนักงาน | 12 | จำนวนพนักงาน 9 + สอบ L1/L2 3 |
| สิ่งแวดล้อม | 10 | ผลตรวจ FC28 ผ่านข้อละ 1 คะแนน |

**ระดับดาว:** 80–100 = 5 ดาว (โบนัส 2 บาท/คิว) · 70–79 = 4 ดาว (1.5) · 60–69 = 3 ดาว (1) · ต่ำกว่า 60 = 2 ดาว (0)

## หมายเหตุสำคัญเรื่องข้อมูล

สิ่งที่พบระหว่างตรวจไฟล์ต้นทาง และวิธีที่ Dashboard จัดการ

1. **คะแนนเต็มคือ 100 ไม่ใช่ 80**
   คำว่า "รวม 80" ในไฟล์กติกาเป็นผลรวมของตารางที่สองเท่านั้น
   เมื่อรวมตารางแรก (ยอดขาย 15 + น้ำยา 5) จึงได้ 100 ซึ่งตรงกับเกณฑ์ดาวในชีต STAR

2. **ไฟล์ SALE ไม่มีช่องคะแนน**
   Dashboard คำนวณคะแนนยอดขายให้อัตโนมัติจากเกณฑ์ในไฟล์กติกา

3. **เกณฑ์ CPK ที่ใช้จริงต่างจากที่เขียนในกติกา**
   จากการตรวจข้อมูลทุกแถวพบว่า ต่ำกว่า 0.55 ได้ 0 คะแนน · ช่วง 0.70–0.80 ได้เต็ม 2.5 ·
   ช่วงอื่นรวมถึงค่าที่เกิน 1.00 ได้ 1.25 คะแนน
   Dashboard ไฮไลท์ตามคะแนนที่ให้จริงในไฟล์ ไม่ได้ยึดข้อความในกติกา

4. **ข้อมูลที่ยังว่างอยู่**
   - `Pointsdeducted.xlsx` ยังไม่มีการบันทึกคะแนนติดลบ Tab หักคะแนนจึงยังไม่มีรายการ
   - ช่อง H2 ของ Safety-Truck ยังว่างทั้งหมด (รอบสอง ก.ค.–ธ.ค. ยังไม่ถึงกำหนดตรวจ)

   เมื่อบันทึกข้อมูลลงไฟล์แล้วรัน `build_data.py` ใหม่ Dashboard จะแสดงผลเองอัตโนมัติ

5. **เกณฑ์การนำโรงงานเข้า Dashboard**
   แสดงเฉพาะโรงงานที่มียอดขายปี 2569 เท่านั้น โรงงานที่ไม่มียอดขายเลย
   (ไม่มีแถวในชีต 2569 หรือมีแถวแต่ยอดรวมเป็น 0) จะถูกตัดออกทั้งหมด
   ปัจจุบันตัดออก 11 โรงงาน เหลือแสดง 288 โรงงาน

   ตอนรัน `build_data.py` จะพิมพ์รายชื่อโรงงานที่ถูกตัดออกให้ดูทุกครั้ง
   ถ้าโรงงานใดเริ่มมียอดขาย โรงงานนั้นจะกลับเข้ามาเองเมื่อรันสคริปต์ใหม่

6. **โรงงานที่ไม่มีใน DATAPLANT**
   บางโรงงานปรากฏในไฟล์อื่นแต่ไม่มีใน DATAPLANT (เช่น FC414, FC412)
   Dashboard เก็บไว้โดยเติมช่องที่ขาดเป็น "ไม่ระบุ" แทนการตัดทิ้ง
   ถ้าต้องการให้ข้อมูลครบ แนะนำให้เพิ่มโรงงานเหล่านี้ลงใน DATAPLANT.xlsx

7. **ชื่อกิจการที่เขียนต่างกัน**
   ไฟล์ Safety และ ENV ใช้ชื่อแบบ Metro / NorthEast ส่วนไฟล์อื่นใช้ 1-Metro / 5-NorthE
   สคริปต์แปลงให้ตรงกันอัตโนมัติแล้ว

## หน้า Login

Dashboard ต้องเข้าสู่ระบบก่อนจึงจะเห็นข้อมูล โดยใช้ **ฐานข้อมูลผู้ใช้จาก Google Sheet**
ผ่าน Apps Script Web App ตัวเดียวกับแดชบอร์ดอื่นในองค์กร ทำให้ username / password
ชุดเดียวกันใช้เข้าได้ทุกแดชบอร์ด

### วิธีการทำงาน

- เรียก Apps Script ด้วย **JSONP** ไม่ใช่ `fetch` เพราะ Apps Script Web App มักติดปัญหา CORS
- `action=login` ตรวจสอบ username / password
- `action=resetPassword` เปลี่ยนรหัสผ่านและบันทึกกลับลง Google Sheet จริง มีผลทุกอุปกรณ์
- ระบบตัด `@scg.com` ท้าย username ออกให้ และไม่สนตัวพิมพ์เล็กใหญ่
- ถ้าเรียก API ไม่สำเร็จ จะลองซ้ำอีกหนึ่งครั้งก่อนแจ้งเตือน
- แสดงหน้า Login ทุกครั้งที่เปิด ไม่ข้ามอัตโนมัติ ถ้าติ๊ก "จดจำฉัน" จะเติม username / password ให้
- ปุ่มเปลี่ยนรหัสผ่านและออกจากระบบอยู่มุมล่างซ้ายของเมนู

### การตั้งค่า

แก้ที่บรรทัดบนสุดของ `auth.js`

```js
const AUTH_API_URL = 'https://script.google.com/macros/s/.../exec';
```

ถ้าเว้นเป็นค่าว่าง `''` ระบบจะถอยไปอ่านผู้ใช้จากไฟล์ `USER.xlsx` ที่วางไว้โฟลเดอร์เดียวกัน
(คอลัมน์: ชื่อ / username / password) ซึ่งกรณีนั้นการเปลี่ยนรหัสผ่านจะเก็บแค่ในเบราว์เซอร์
เครื่องนั้นเท่านั้น ไม่ซิงก์ไปเครื่องอื่น

## ถ้าหน้าจอแสดงผลไม่ตรงกับที่ควรจะเป็น

อาการที่พบบ่อยคือ **ช่องค้นหาบางช่องว่างเปล่า ไม่มีตัวเลือกให้เลือก**
หรือข้อความบนหน้าจอยังเป็นแบบเก่า สาเหตุเกือบทั้งหมดคือเบราว์เซอร์ยังใช้ไฟล์เดิมที่เก็บไว้ใน cache

วิธีแก้ตามลำดับ

1. กด **Ctrl + F5** (Windows) หรือ **Cmd + Shift + R** (Mac) เพื่อบังคับโหลดไฟล์ใหม่
2. ตรวจว่าอัปโหลดไฟล์ **ครบทุกไฟล์** โดยเฉพาะ `app.js` `data.js` และ `styles.css`
   การอัปโหลดแค่ `index.html` ไฟล์เดียวจะทำให้หน้าจอผสมกันระหว่างเวอร์ชันเก่ากับใหม่
   (ตั้งแต่เวอร์ชัน 7 มีไฟล์ `auth.js` เพิ่มเข้ามาด้วย)
3. ดูมุมซ้ายล่างของเมนู ต้องขึ้นว่า **เวอร์ชัน 11** ถ้าไม่ขึ้นแปลว่ายังใช้ไฟล์เก่าอยู่

Dashboard มีระบบตรวจสอบให้อัตโนมัติ ถ้าพบว่าช่องค้นหาช่องใดไม่มีตัวเลือก
จะขึ้นข้อความเตือนที่ด้านล่างจอทันทีว่าให้กด Ctrl+F5

## รายละเอียดทางเทคนิค

- HTML/CSS/JavaScript ล้วน ไม่ต้องใช้ build tool
- ไม่มีการเรียก API ภายนอก ข้อมูลทั้งหมดอยู่ใน `data.js`
- ฟอนต์โหลดจาก Google Fonts (IBM Plex Sans Thai) และมีฟอนต์สำรองในเครื่องกรณีออฟไลน์
- รองรับหน้าจอมือถือ และรองรับการใช้แป้นพิมพ์
